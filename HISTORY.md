# 📜 Campus Compass - Project History & Changelog

## 📌 Project Overview
**Campus Compass** is an interactive smart college companion web application built for college freshers, current students, and campus visitors.

---

## 🚀 Version History

### [v1.2.0] - 2026-11-09
#### ✨ Added
- **Project List History**:
  - Saved campus snapshots with timestamps, spot counts, and metadata.
  - One-click switching between campus project configurations.
  - Ability to save current customized campus setups directly to Project History (`localStorage`).
  - History management (load, export JSON, delete snapshots).
- **Comprehensive File Import / Export Engine**:
  - Native `.json` file backup and spots import.
  - Native `.csv` spreadsheet parser with custom column mapping and amenities handling.
  - Live data preview with Merge (append) and Replace (overwrite) import modes.
  - One-click JSON backup and CSV spreadsheet exports.
- **Sample Datasets & Templates**:
  - Preloaded with `campus_compass_backup_sample.json` (MIT-WPU dataset).
  - Preloaded with `campus_spots_sample.csv` (Spreadsheet sample).
- **Navigation Shortcuts**:
  - Added "Projects & Files" trigger in Navbar and quick mobile action bar.
  - Added "Import Files" button in Campus Directory.
  - Dynamic coordinate plotting on the interactive campus map for all imported locations.

---

### [v1.1.0] - 2026-11-04
#### ✨ Core Application Launch
- **Dual Audience Persona Switcher**: Fresher Mode vs. Visitor Mode.
- **Campus Spots & Labs Directory**: Category and zone filters with senior tips.
- **Interactive Campus Grid & Wayfinding**: Coordinate pins with estimated walking times and route preview.
- **Food Radar**: Canteen crowds, budget tiers, and signature items.
- **Clubs & Events Hub**: Technical, cultural, and sports societies with 1-click RSVP.
- **Senior Survival Kit & FAQs**: Wi-Fi guides, printing spots, curfews, and emergency helplines.
- **AI Peer Mentor (Senior AI Assistant)**: In-app peer mentoring assistant.
- **My Tour Planner**: Persistent itinerary checklist.
